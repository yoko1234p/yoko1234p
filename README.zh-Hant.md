## 從這裏開始

每個項目均有獨立原始碼、建置步驟和預覽版下載。macOS 預覽版使用臨時簽署，未經 Apple 公證；請依照各 repo 的安裝說明操作。TG Local 是透過開發人員模式載入的 Chrome 擴充。

## 參與開發

請到相關項目開 Issue，註明 macOS 或 Chrome 版本、重現步驟及實際情況。原創 App 程式碼採 GPL-3.0-only；第三方素材保留各自授權聲明。
