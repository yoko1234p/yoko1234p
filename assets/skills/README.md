# Skill icon attribution

The technology logos in this directory, including the `*-original.svg` files and the AWS wordmark, come from [Devicon](https://github.com/devicons/devicon) and retain its MIT license in `DEVICON-LICENSE.txt`.

The SwiftUI, AppKit, Claude Code and Codex symbols are original illustrations for this profile. They are labels for the technologies and tools, not official product marks. `tile-*.svg` combines these symbols or Devicon SVGs with the profile's original card design.
