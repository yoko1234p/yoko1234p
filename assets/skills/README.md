# Skill icon attribution

The technology logos in this directory, including the `*-original.svg` files and the AWS wordmark, come from [Devicon](https://github.com/devicons/devicon) and retain its MIT license in `DEVICON-LICENSE.txt`.

The SwiftUI, AppKit, Claude Code and standalone `codex.svg` symbols are original illustrations for this profile, not official product marks. `tile-*.svg` combines these symbols or Devicon SVGs with the profile's original card design.

`openai-blossom.svg` is the black Blossom from [OpenAI’s official logo package](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip); its vector is displayed in `tile-codex.svg` to identify Codex. The mark belongs to OpenAI; see its [design guidelines and usage terms](https://openai.com/brand/).
