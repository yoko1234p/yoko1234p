## 从这里开始

每个项目均有独立源代码、构建步骤和预览版下载。macOS 预览版使用临时签名，未经 Apple 公证；请按各仓库的安装说明操作。TG Local 是通过开发者模式加载的 Chrome 扩展。

## 参与开发

请到相关项目提交 Issue，注明 macOS 或 Chrome 版本、复现步骤及实际情况。原创应用代码采用 GPL-3.0-only；第三方素材保留各自许可声明。
